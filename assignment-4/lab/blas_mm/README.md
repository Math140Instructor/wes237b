## How to Compile
The `main.cc` file contains the host code for the programming assignment. There is a Makefile included which compiles it and links it with library helper functions. It can be run by typing `make` from the `blas_mm` folder. It generates a `solution` output file. During development, make sure to run the `make clean` command before running `make`.

## How to Test
Use the make run command to test your program on the test cases in the Dataset foldeer. There are a total of 10 tests on which your program will be evaluated.
